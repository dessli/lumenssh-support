LumenSSH Support

A native macOS workbench for SSH terminals, SFTP, tunnels and multi-server workflows.

Get help

Report a bug or request a feature. A GitHub account is needed to submit an issue. This is a public support channel; include only sanitized information. Private support messaging is not currently available here.

Never post passwords, private keys, API keys, IP addresses, host names, terminal output or unredacted screenshots. For security reports, use private vulnerability reporting if enabled. If that form is unavailable, open a public issue asking for a private contact method without including vulnerability details.

Connection troubleshooting

  1. Confirm the server address, port and username in Machines.
  2. Assign a local credential in Identities. Imported OpenSSH profiles require a separate authorized private-key selection.
  3. Verify host-key changes with your server administrator before trusting a new fingerprint.
  4. Use Test Connection and share only a redacted error category.

Purchases and subscriptions

Restore Purchases is available in Settings → Subscription. The optional 14-day trial does not renew automatically. Monthly subscriptions renew unless cancelled through Apple. A lifetime purchase does not automatically cancel an existing monthly subscription.

Privacy and deletion

Read the full privacy policy. Settings → Privacy provides local data and iCloud metadata deletion controls. LumenSSH does not collect advertising or third-party analytics. Optional AI uses your configured provider and requires consent.
